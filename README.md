# Telegram Business NFT Offers Bot

Готовое решение для создания интерактивных офферов покупки/передачи Telegram NFT-подарков через Telegram Business с системой платных подписок и кастомными Telegram Premium эмодзи (Stars и Gram).

---

## ⚡ Особенности

- **Telegram Business интеграция:** работает напрямую в чатах через подключенный бизнес-аккаунт.
- **Система подписок:** создавать офферы могут только пользователи с активной подпиской. Без подписки сообщение автоматически заменяется на: `подписка окончена.`
- **Строгая фиксация получателя:** подарки по кнопке «Передать подарок» передаются **строго** на указанный в конфиге аккаунт (`TARGET_RECIPIENT_USERNAME` / `TARGET_RECIPIENT_ID`). Пользователи не могут подменить юзернейм получателя через команду.
- **Поддержка двух валют с кастомными эмодзи:**
  - ⭐️ **Stars:** кастомная белая звезда из набора `TgAndroidIcons`
  - 🪙 **GRAM:** кастомная монета из набора `FinanceEmoji`
- **Живой таймер:** сообщение с оффером динамически обновляет оставшееся время до окончания действия предложения.
- **Интерактивные кнопки:**
  - `Принять` — открывает инструкцию передачи подарка с кнопками «Передать подарок» и «Подтвердить передачу».
  - `Отклонить` — мгновенно отменяет оффер.
  - `Подтвердить передачу` — показывает уведомление о проверке транзакции в блокчейне.
- **Панель администратора:** управление списком подключенных бизнес-аккаунтов, выдача/аннулирование подписок, назначение со-администраторов.

## 🚀 Быстрый старт

### 1. Настройка бота в @BotFather
1. Создайте бота через [@BotFather](https://t.me/BotFather) (`/newbot`).
2. Включите режим Telegram Business:
   - Отправьте команду `/mybots`
   - Выберите своего бота
   - Нажмите `Bot Settings` -> `Telegram Business` -> `Turn On` (разрешить подключение к бизнес-аккаунтам).

### 2. Установка зависимостей
```bash
python -m venv venv
# Linux / macOS:
source venv/bin/activate
# Windows:
# venv\Scripts\activate

pip install -r requirements.txt
```

### 3. Конфигурация (.env)
Скопируйте `.env.example` в `.env`:
```bash
cp .env.example .env
```
Заполните параметры:
- `BOT_TOKEN` — токен бота от BotFather.
- `MASTER_ADMIN_ID` — ваш цифровой Telegram ID (узнать можно через @userinfobot или написав /id боту).
- `TARGET_RECIPIENT_USERNAME` — юзернейм аккаунта, которому отправляются подарки (без @).
- `TARGET_RECIPIENT_ID` — цифровой Telegram ID получателя подарков.
- `EMOJI_STAR_ID` — ID кастомного эмодзи звезды (по умолчанию: `5960672896060756972`).
- `EMOJI_GRAM_ID` — ID кастомного эмодзи Gram (по умолчанию: `5377620962390857342`).

### 4. Запуск
```bash
python main.py
```

## 📲 Подключение бота к аккаунту Telegram Business

1. Откройте **Telegram** на телефоне или компьютере.
2. Перейдите в **Настройки** -> **Telegram Business** -> **Чат-боты** (Chatbots).
3. Введите юзернейм вашего бота (например, `@OffersNftGiftsRobot`).
4. Нажмите **Добавить** и включите все разрешения (включая «Управлять сообщениями»).
5. Выдайте себе или клиенту подписку через бота перед отправкой офферов.

## 👑 Команды администратора (в ЛС боту)

- `/give <ID> <срок>` — выдать подписку пользователю на указанный срок:
  - `/give 123456789 2 дня`
  - `/give 123456789 12 часов`
  - `/give 123456789 1 месяц`
  - `/give 123456789 1 год`
  *(Поддерживаются: минуты/мин/m, часы/ч/h, дни/дней/d, недели/w, месяцы/m, года/y)*
- `/take <ID>` — аннулировать подписку пользователя.
- `/subs` — список всех активных подписок со сроками действия.
- `/offer` — интерактивная инлайн-панель:
  - Просмотр всех подключенных бизнес-аккаунтов (активен / отключен, статус подписки, быстрая выдача в 1 клик).
  - Управление администраторами (добавление новых админов по юзернейму или ID).
  - Статистика в реальном времени.

## 💼 Команды создания офферов (в чатах через Telegram Business)

Пользователь с активной подпиской пишет в любом личном диалоге:

### Оффер в Звездах (Stars):
```text
/offers https://t.me/nft/snoopdogg-1389 5000 24
```
или кратко:
```text
/offers Snoop Dogg 1389 5000
```
- Сообщение автоматически преобразуется в интерактивную карточку с таймером и кнопками.

### Оффер в GRAM:
```text
/offers https://t.me/nft/snoopdogg-1389 5000 24 gram
```
или:
```text
/goffers https://t.me/nft/snoopdogg-1389 5000 24
```

> **Безопасность:** Получатель подарка зафиксирован на уровне сервера. Попытки передать аргументы вроде `/offers ... @otheruser` игнорируются — кнопка «Передать подарок» всегда ведет на целевого получателя из конфига.
> Если у отправителя нет активной подписки, бот автоматически заменит сообщение на: `подписка окончена.`

## 🖥️ Развертывание на Linux (Systemd Service)

Создайте файл службы:
```bash
sudo nano /etc/systemd/system/tg-offers-bot.service
```

Вставьте конфигурацию:
```ini
[Unit]
Description=Telegram Business NFT Offers Bot
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/tg-offers-bot
ExecStart=/usr/bin/python3 /root/tg-offers-bot/main.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

Активируйте и запустите:
```bash
sudo systemctl daemon-reload
sudo systemctl enable tg-offers-bot
sudo systemctl start tg-offers-bot
sudo systemctl status tg-offers-bot
```
